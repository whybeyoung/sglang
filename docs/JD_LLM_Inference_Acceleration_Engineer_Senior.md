# 大模型推理加速优化工程师（高阶）

## 我们正在做的事

大模型已进入「推理即战场」：首包延迟、吞吐、显存与多卡协同直接决定体验与成本。我们在这条链路上做性能优化与稳定性建设，支撑高并发、低延迟的在线推理，把算法能力转化为可规模化的服务；期待你既能扎进 kernel 与调度，也能从分布式与架构视角做权衡与设计。

---

## 岗位职责

- **最主流开源技术与生产力工具**：深度参与主流开源推理框架的二次开发与定制，将核心能力在业务中落稳、调优，追求「跑得好」。
- **最具潜力的 MaaS 平台**：在 MaaS 平台上做推理引擎的性能与稳定性建设，让高并发、低延迟可预期、可运维，支撑算法能力规模化落地。
- **最具挑战的技术目标**：攻克首包延迟、吞吐、显存与多卡协同；参与分布式推理架构设计与突破；将新模型、新特性稳定接入推理链路。

---

## 任职要求

- **学历与经验**：计算机/数学/电子等相关专业本科及以上，3 年以上大模型或高性能推理/训练相关开发经验。
- **推理框架**：熟练使用并深入理解 SGLang、vLLM 至少一种，具备源码级阅读、问题定位与二次开发能力；理解其调度、内存、kernel 与分布式设计，能独立排查与优化复杂问题。
- **性能与系统**：有 GPU 推理性能 profiling 经验（Nsys/Nsight、CUDA/Triton），能定位 kernel、显存、通信与调度瓶颈，并推动优化落地。
- **编程与工程**：扎实的 C++/Python 基础；有 CUDA、Triton 或其它 GPU 编程经验者优先；代码规范、可维护，有文档与协作习惯。
- **加分项**：有 FlashInfer、DeepSpeed-Inference、TensorRT-LLM、TGI 等推理/服务化经验；熟悉 PyTorch 模型结构与导出；有大规模推理集群运维或 SLO 保障经验。
